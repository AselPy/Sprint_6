# Sprint_6 — Автоматизация тестирования сервиса «Самокат»

## Описание проекта

Проект предназначен для автоматизации тестирования учебного сервиса «Самокат» с использованием Selenium, pytest и Allure.

## Используемые технологии

- Python
- Selenium
- pytest
- pytest-параметризация
- Page Object Model (POM)
- Allure

## Структура проекта

- `locators/` — локаторы элементов страницы.
- `page_objects/` — классы страниц и общие методы взаимодействия с браузером.
- `test/` — автоматизированные тесты.
- `conftest.py` — фикстура для запуска и закрытия браузера.
- `data.py` — тестовые данные и ожидаемые ответы FAQ.
- `urls.py` — адрес тестируемого сервиса.
- `requirements.txt` — зависимости проекта.
- `.gitignore` — файлы и папки, исключённые из Git.

## Тестовые сценарии

### Вопросы о важном (FAQ)

Проверяется раскрытие ответов на все восемь вопросов FAQ и соответствие ответов ожидаемому тексту.

### Оформление заказа

Проверяется позитивный сценарий оформления заказа с двумя наборами тестовых данных.

### Навигация

Проверяются:
- открытие формы заказа по нижней кнопке «Заказать»;
- переход на главную страницу по логотипу «Самокат»;
- открытие Дзена по логотипу Яндекса в новой вкладке.

## Установка и подготовка

Для запуска проекта необходимы Python, Mozilla Firefox и Allure Commandline.

Установить зависимости Python:

```bash
py -m pip install -r requirements.txt
```

## Запуск тестов

Запустить все тесты:

```bash
py -m pytest test
```

Запустить тесты с сохранением результатов для Allure:

```bash
py -m pytest test --alluredir=allure-results
```

## Формирование Allure-отчёта

Создать HTML-отчёт на основе результатов тестирования:

```bash
allure generate allure-results -o allure-report --clean
```

Открыть сформированный отчёт:

```bash
allure open allure-report
```

## Результат

Автоматизированы основные сценарии проверки FAQ, навигации и оформления заказа. Для анализа результатов тестирования используется Allure.
