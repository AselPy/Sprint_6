
# Sprint_6 — Автоматизация тестирования сервиса «Самокат»

## Описание проекта

Проект предназначен для автоматизации тестирования учебного сервиса «Самокат» с использованием Selenium, pytest и Allure.

## Используемые технологии

- Python
- Selenium
- pytest
- pytest-параметризация
- Page Object Model
- Allure

## Структура проекта

- `page_objects/` — классы страниц и локаторы.
- `test/` — автоматизированные тесты.
- `conftest.py` — фикстура запуска и закрытия браузера.
- `requirements.txt` — внешние зависимости проекта.
- `.gitignore` — файлы и папки, исключённые из Git.
- `allure-report/` — сформированный HTML-отчёт Allure.

## Тестовые сценарии

### Вопросы о важном

Проверяется раскрытие ответов на все восемь вопросов FAQ.

### Оформление заказа

Проверяется позитивный сценарий заказа с двумя наборами тестовых данных.

### Навигация

Проверяются нижняя кнопка «Заказать», переход на главную страницу по логотипу «Самоката» и открытие Дзена по логотипу Яндекса.

## Установка зависимостей

Для запуска проекта необходимы Python, Mozilla Firefox и установленный Allure Commandline.

Установить зависимости Python:

```bash
py -m pip install -r requirements.txt
```

## Запуск тестов

Запустить все тесты:

```bash
py -m pytest test
```

Запустить тесты с сохранением результатов для Allure:

```bash
py -m pytest test --alluredir=allure_results
```

## Формирование Allure-отчёта

Создать HTML-отчёт:

```bash
allure generate allure_results -o allure-report --clean
```

Открыть отчёт:

```bash
allure open allure-report
```
Статус проекта: автоматизированные тесты и HTML-отчёт Allure подготовлены.
